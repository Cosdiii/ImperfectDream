# ImperfectDream
# 🎮 2D 敘事解謎遊戲專案 (Unity 3D / C#)

🎓 本專案為大學畢業製作，我擔任**主要程式開發者**，負責核心遊戲機制、對話系統與解謎邏輯的實作。


---

## 📌 專案簡介 (Overview)
* **遊戲類型**：2D 橫向/俯視 敘事解謎遊戲
* **開發工具**：Unity3D, C#, Visual Studio
* **專案職責**：獨立負責全案程式架構、解謎機制邏輯、對話流程整合與 UI 控制。

---

## 🛠️ 核心程式架構與技術亮點 (Technical Highlights)

### 1. 💬 對話與敘事系統 (Dialogue System)
* **Flower System 整合**：採用 Flower 文本對話框架，實現多分支對話與劇情觸發邏輯。
* **事件驅動設計**：將對話觸發與場景解謎連動，優化玩家劇情體驗與程式碼耦合度。

### 2. 🧩 敘事解謎與物件互動 (Puzzle & Interaction Logic)
* **環境調查與互動機制**：實作玩家與場景物件之碰撞檢測、調查提示與線索獲取邏輯。
* **狀態與進度管理**：使用 C# 腳本控管解謎機關開關與關卡進度狀態，確保遊戲流程順暢不卡關。

### 3. 🎨 遊戲 UI 與流程控制 (UI & Flow Control)
* **UI 模組化控制**：控管主選單、對話介面、調查提示與遊戲選單的顯示與切換。
* **場景載入與切換**：妥善處理場景轉換時的資料傳遞與玩家位置重置。
